# Прототип сайта спа-салона в Москве

Одностраничный прототип для нового клиента веб-студии. Визуальная система — **Soft Editorial** (тёплая бумага, Playfair Display, Manrope, терракота и шалфей).

Живая страница: https://bilarius1-tech.github.io/spa-salon-prototype/

## Что внутри

- Первый экран, анкеты мастеров, конструктор визита, система скидок, запись и контакты
- Одна базовая услуга — «Массаж, 1 час» — и дополнительные услуги (допы), плюс готовые комбо
- Формат «В салоне» или «С выездом»; все мастера с бейджем «Выезд на дом»
- Адаптив для компьютера и мобильного
- Форма записи только на фронтенде: показывает состояние «заявка отправлена (прототип)» и подтягивает состав визита из конструктора
- Название салона, адрес, телефон, цены и рейтинги — заполнители. Цены в конструкторе примерные, правятся в объекте `PRICE` в `js/main.js`

Названия бренда нет: в шапке текстовый вордмарк «Название салона».

## Запуск локально

Откройте `index.html` в браузере или поднимите любой статический сервер в корне репозитория. Сборки нет.
